## Selected Projects

### [PersonalOS](https://github.com/urieltisera/PersonalOS-Portfolio)
A governed execution layer for agent systems, designed around explicit authorization, Human Gates, execution authority, recovery, auditability, and deterministic runtime eligibility. The portfolio version is maintained as a stable snapshot while active development continues privately.

**Focus:** Agent governance · authorization · recovery · auditability · deterministic execution

### [StrideFrame](https://github.com/urieltisera/StrideFrame-Portfolio)
A sports photography SaaS with full-stack product flows, payment infrastructure, secure photo delivery, and computer-vision foundations. Includes Stripe Connect foundations, manually verified Zelle payments, refunds/disputes, download revocation, and event-scoped face search.

**Stack:** Next.js · TypeScript · PostgreSQL · Prisma · pgvector · Docker · Stripe

### [Atlas Systems](https://github.com/urieltisera/Atlas-Systems-Portfolio)
A Python backend for governed business automation and external integrations. It uses ports and adapters, tenant boundaries, capability controls, durable delivery state, encrypted credential references, and Telegram/WhatsApp integration foundations.

**Stack:** Python · automation · Telegram · WhatsApp · SQLite · Docker

### [B1 RAG Core](https://github.com/urieltisera/B1-RAG-Core-Portfolio)
A tenant-scoped retrieval service built as an explicit infrastructure boundary for AI systems. It combines FastAPI, PostgreSQL/pgvector, embeddings, retrieval contracts, and database migrations without treating caller-supplied tenant context as authentication.

**Stack:** Python · FastAPI · PostgreSQL · pgvector · SQLAlchemy · Alembic · embeddings

### [Nambre](https://github.com/urieltisera/Nambre-Portfolio)
A multi-tenant SaaS for permanent QR experiences and evolving digital menus. It includes authentication and access controls, stable public QR routes, menu foundations, plan/entitlement foundations, auditability, migrations, and containerized deployment foundations.

**Stack:** FastAPI · Next.js · PostgreSQL · Alembic · Docker

### [MCExcelBot](https://github.com/urieltisera/MCExcelBot)
A Telegram automation project for generating structured Excel workbooks from guided user flows, with reusable templates, validation, QR generation, and an experimental document-digitization direction.

**Stack:** Python · python-telegram-bot · openpyxl · Pillow · QR automation
